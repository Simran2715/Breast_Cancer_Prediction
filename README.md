# Breast_Cancer_Prediction
🔐 Logistic Regression – Binary Classification Project

This project demonstrates a complete binary classification pipeline using Logistic Regression. It includes dataset preparation, feature standardization, model training, performance evaluation, and threshold tuning.

Key components:

Binary dataset selection

Train/test split & feature standardization

Logistic Regression model training

Evaluation using confusion matrix, precision, recall, and ROC-AUC

Threshold tuning with explanation of the sigmoid function
